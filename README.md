# Мой кинотеатр 0.8.5 для Lampa

Подключение: `https://sargeryz.github.io/lampa-stream/plugin.js`.

После установки откройте карточку фильма или сериала, выберите «Мой кинотеатр». Для проверки Cinema: настройки расширения → режим «Источники Cinema», затем откройте карточку заново. В режиме «Все подключения» Cinema включён по умолчанию; его можно отдельно отключить или изменить адрес.

Cinema использует JSON API стороннего Lampac. Доступность сервера и источников зависит от их владельцев. HTTP может блокироваться в браузерной версии Lampa. Свой Lampac, личный API, каталог и прямые адаптеры остаются отдельными подключениями. Расширение не выполняет RCH-команды и не отправляет сохранённый email или приватные токены публичному Cinema.

## Версия 0.8.5

Нажатие на фильм или серию сразу запускает лучшее доступное разрешение без меню качества. Варианты сортируются по разрешению, независимо от порядка в JSON; поддерживаются также обозначения 4K/UHD и размеры кадра. Для следующей серии выбирается лучшее качество из обновлённого ответа. Резервный адрес соответствует выбранному качеству. В списке показано лучшее доступное разрешение.

Публичный WTCH Filmix при повторной проверке «Одних из нас», LostFilm, сезон 1 вернул только 720p и 480p. 1080p поддерживается адаптером, когда источник присылает такую ссылку; подписанные URL не переделываются для получения отсутствующего качества. У Filmix возможность Full HD зависит от доступа аккаунта и используемого API: [официальное описание](https://filmix.gg/pro.html). В проверенных запросах WTCH HDVB и Vibix вернули HTTP 502, поэтому наличие рабочего 1080p через них не подтверждено.

Живая проверка WTCH подтвердила запуск 720p без диалога и обновление ссылки на следующую серию. Интеграционные проверки на Lampa 3.3.8 и сборке bylampa.online 3.3.1 дополнительно подтверждают выбор 1080p/4K, сортировку вариантов с меньшим качеством в начале списка, резервный адрес, игнорирование неподдерживаемых URL и выбор лучшего качества следующей серии. Воспроизведение видеоданных на устройстве этими проверками не проверялось.

## Версия 0.8.4

Исправлено открытие раздела настроек: все текстовые поля регистрируются с `values: ''`, как требует обработчик `Params.update` в Lampa. Пустые поля показывают «Не задано». Проверяется создание настоящего экрана настроек и выбор режима WTCH с сохранением после повторного открытия.

## Версия 0.8.3

У источников Cinema убрана приписка «• Cinema» в меню и шапке. Превью выбирается из ответа источника, затем из кадра серии, фона или постера карточки. При ошибке изображения загружается следующий вариант; для результатов поиска других фильмов и демо картинка открытой карточки не подставляется. На загруженном превью фильма скрывается большая кнопка воспроизведения, а номер серии показан в углу.

## Версия 0.8.2

WTCH также получает 30 секунд на обнаружение источников. Для проверки: режим «Готовый сервер WTCH» → заново открыть сериал → источник Filmix → качество 720p. Его JSON API `/lite/fxapi` при проверке без личного токена вернул девять серий первого сезона «Одних из нас» и разные ссылки для 720p и 480p. Доступное качество определяется ответом конкретного источника, а не надписью в рекламном баннере. Загрузчик `/m` подключает `/online.js`; для нашего адаптера достаточно API, без загрузки стороннего клиентского кода.

## Версия 0.8.1

Cinema получает 30 секунд на обнаружение источников вместо 8: при повторной проверке точный запрос карточки вернул HTTP 200 примерно за 16 секунд. Ошибки различают тайм-аут, HTTP-код, неверный JSON, отмену и отсутствие HTTP-ответа. Сообщения не выводят query-параметры и текст ответа сервера. При запросе HTTP API из HTTPS-страницы показывается возможная причина блокировки; это не подтверждает её на конкретном устройстве. Увеличение тайм-аута не устраняет недоступность сервера или ограничения браузера.

## Версия 0.8.0

- Сезон и перевод сохраняются локально для каждой карточки и источника; «Сбросить фильтр» очищает выбор.
- Встроенный плеер получает плейлист серий одного сезона в порядке номеров. Ссылка на следующую серию обновляется при выборе: через резолвер `call` или повторное получение списка для прямых `play`-ссылок.
- Резервная ссылка `url_reserve` соответствует выбранному качеству. Метаданные, заголовки, субтитры и сегменты сохраняются в данных плеера.
- Внешние плееры получают конкретные адреса; для источников с `call` передаётся только выбранная серия.
- Неактивные источники `show=false` скрываются. Выбор другого источника доступен и после ошибки первого.

## Проверки

Синтаксис: `npm test`.

Интеграционные проверки используют настоящие компоненты Lampa и сетевые фикстуры:

```bash
npm install
git clone --depth 1 https://github.com/yumata/lampa.git ../lampa-runtime
npm run test:native
```

Можно указать другой каталог Lampa: `npm run test:native -- /путь/к/lampa`.

Проверено на Lampa 3.3.8: меню, сохранение выбора, плейлист, обновление ссылок, резервные адреса, отказ источника, изоляция токенов, каталог и демо. Дополнительно живой API Cinema вернул девять серий первого сезона «Одних из нас» и повторно выдал ссылку при переходе ко второй серии. В проверенном ответе было 480p. Видеоданные не загружались; воспроизведение на телевизоре и ограничения браузера этим тестом не проверяются.
